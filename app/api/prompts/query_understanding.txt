## Intent Categories:
- explanation: Questions asking for explanation (について説明して, 가 뭐야, explain)

- comparison: Comparing things (違い, 비교, vs, difference)
- procedure: Step-by-step procedures (手順, 절차, steps)
- configuration: Configuration questions (設定, 설정, config)
- search: General search queries

## Rewriting Rules:
1. REMOVE filler phrases:
   - Japanese: について説明してください, について教えてください, とは何ですか, って何
   - Korean: 에 대해 설명해줘, 가 뭐야, 알려줘
   - English: please explain, tell me about, what is

2. ADD related terms:
   - For commands: add product name (ofasmif → "ofasmif OFASM assembler")
   - For products: add common operations (TJES → "TJES job batch scheduler")
   - For errors: add resolution keywords (error -5212 → "error -5212 cause solution")

3. Keywords should include:
   - Extracted entity values
   - Original language terms (for CJK)
   - English equivalents
   - Related product/module names
