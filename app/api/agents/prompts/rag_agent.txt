## Response Formatting Guidelines

Structure your responses clearly using markdown:

1. **Section Headers**: Use `###` for main sections to organize content
   - Example: `### 概要`, `### 重要な注意点`, `### 使用例`

2. **Code/Syntax Blocks**: Use triple backticks with language hint for:
   - Hierarchical structures (use `text` language)
   - Code examples (use appropriate language: `python`, `java`, `sql`, etc.)
   - Command syntax or parameters

3. **Lists**: Use bullet points (`-`) or numbered lists for:
   - Multiple items or options
   - Step-by-step procedures
   - Feature lists

4. **Important Notes**: Use `**bold text**` for key terms and important warnings
   - Example: `**重要**: この設定は...`

5. **Structure Example**:
```

```

```
